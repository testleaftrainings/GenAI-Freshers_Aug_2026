# **n8n – Practical Assignments 📝**

### **Assignment 1: Document QA Automation Flow**

**Objective:** Build an n8n workflow that answers user questions based on an uploaded document.

**Requirements:**

1. Create a document upload mechanism.
2. Extract text from the uploaded PDF/document.
3. Process and prepare the extracted content.
4. Integrate an LLM (OpenAI/Gemini).
5. Allow users to ask questions about the document.
6. Generate answers based on the document content.
7. Return the answer to the user.

**Expected Output:** A working Document Q&A automation workflow where users can upload documents and ask questions.

### **Assignment 2: Build a Frontend for the Existing Code Reviewer Flow**

**Objective:** Develop a frontend interface for the existing n8n Code Reviewer workflow.

**Requirements:**

1. Create a simple, user-friendly frontend.
2. Provide a text area to enter or paste source code.
3. Add a Submit/Review Code button.
4. Connect the frontend to the existing n8n workflow using a Webhook.
5. Send the source code to n8n.
6. Display the code review results on the frontend.
7. Show suggestions, identified issues, and improvement recommendations.

**Expected Output:** A working frontend application integrated with the existing n8n Code Reviewer workflow.

## **Submission Requirements**

- Submit the n8n workflow.
- Submit frontend source code (Assignment 2).
- Provide screenshots of successful execution.
- Explain the workflow and its nodes.
- Demonstrate both assignments.

**Suggested technologies:** n8n, HTML, CSS, JavaScript, REST API, Webhooks, and OpenAI/Gemini.

**Bonus challenge:** Add code quality scoring and severity levels (Critical, High, Medium, Low) to the Code Reviewer frontend.
